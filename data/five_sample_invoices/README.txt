FIVE SAMPLE INVOICES
====================

Five synthetic PDF tax invoices for testing an invoice extraction pipeline.
All names and invoice details are fictional. GSTIN-like values are synthetic and not valid for real transactions.

Files:
- invoice_01_office_supplies.pdf
- invoice_02_it_services.pdf
- invoice_03_marketing.pdf
- invoice_04_equipment.pdf
- invoice_05_consulting.pdf
- sample_ground_truth_reference.json: expected values for comparison; these are not model predictions.
